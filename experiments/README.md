# Experiments

This folder stores the experimental runs used to compare the finite-difference solver, data-driven neural network, and PINN.

Each experiment is a self-contained record containing the shared experiment configuration, computing environment, method configurations, raw outputs, evaluation metrics, and computational performance.

Experiment folders will follow:

`experiment_001/`, `experiment_002/`, `experiment_003/`, ...

The individual experiment folders are the source of experimental data. Summary CSV files, tables, and graphs will be generated from these records for analysis.
