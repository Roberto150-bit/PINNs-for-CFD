## B2. The thesis in one paragraph

The thesis asks whether training a neural network with Navier–Stokes physics improves physical consistency enough to justify its extra computational cost. The test problem is 2D incompressible lid-driven cavity flow in the unit square. The top lid moves at u = 1; the other three walls are no-slip. Three methods are compared:

| Method | Trained on | Role |
| --- | --- | --- |
| Finite-difference (FD) solver | Nothing (numerical method) | Reference solution, the data source for the data NN, and a cost baseline |
| Data-driven NN | FD data only, no physics | Benchmark: what a network learns from data alone |
| PINN | Physics only: PDE residuals plus boundary and initial conditions. No FD data at all | The method under test |

Research questions: (RQ1) accuracy of u, v, p against FD; (RQ2) how well each model satisfies continuity and momentum; (RQ3) data NN vs PINN on physical consistency and repeatability; (RQ4) computational cost, meaning training time, inference time, memory and storage, on CPU and GPU. The thesis is computer-science heavy, so cost and systems measurements are first-class results.

Fixed decisions: TensorFlow/tf.keras (installed: TF 2.22.0-rc0, Python 3.14, record this); time-dependent problem with inputs (x, y, t) and outputs (u, v, p); 64 × 64 reference grid; Re 100 and Re 400; CPU (Intel i5-12450H, 8 cores, 12 threads) and GPU (RTX 4060 Laptop, 8 GB) measured separately; the Intel UHD iGPU is unused, since TensorFlow has no path to it; five seeds per core configuration.

## B5. Technical specification

### FD reference

- Grids 32, 64 and 128 (64 is the reference); Re 100 (ν = 0.01) and Re 400 (ν = 0.0025); Δt = 0.001; ρ = 1. At 128 the viscous number is ν Δt / Δx² = 0.16, under 0.25, and the Courant number is 0.13.
- Transient run from rest with the lid ramp: save 51 snapshots of (u, v, p) at t = 0.0, 0.1, …, 5.0.
- Write each run into the experiment layout from `notes/week-03.md`, with `config.json`, `solution.npz` (x, y, t, u, v, p), `performance.json` and `history.csv`.
- Keep a `--legacy` flag that reproduces the original 21 × 21 behavior exactly.

### Dataset (per Re, from the 64 × 64 transient)

- 64 × 64 × 51 = 208,896 space-time points.
- Test B (time interpolation): 10 whole snapshots, t = 0.5, 1.0, …, 5.0, never used in training. That is 40,960 points.
- The remaining 41 snapshots (167,936 points) split 70/15/15 at random with seed 0: train 117,555, validation 25,190, test A 25,191.
- Save the split indices with the dataset so every run uses identical splits.

### Shared network (both NNs)

- Inputs (x, y, t) scaled to [−1, 1]; outputs (u, v, p).
- 5 hidden layers × 64 neurons, tanh, Glorot initialization: **17,091 trainable parameters**.
- Adam, learning rate 1e-3, **20,000 optimizer steps** for both methods. The data NN uses batch 4,096; the PINN uses the full collocation set each step. Steps never change between runs; the reason is comparability.
- Seeds: Python, NumPy and TF seeded per run. Call `tf.config.experimental.enable_op_determinism()` in every run, and measure its speed cost once.

### Data NN loss

Train on standardized outputs (mean and standard deviation from the train split). All metrics are computed in physical units.

```math
\mathcal{L}_{data} = \tfrac{1}{3}\left(\mathrm{MSE}_u + \mathrm{MSE}_v + \mathrm{MSE}_p\right)
```

### PINN loss (physics only, no FD data)

Unsteady incompressible Navier–Stokes, ρ = 1:

```math
r_c = u_x + v_y
```
```math
r_x = u_t + u u_x + v u_y + p_x - \nu (u_{xx} + u_{yy})
```
```math
r_y = v_t + u v_x + v v_y + p_y - \nu (v_{xx} + v_{yy})
```
```math
\mathcal{L}_{PINN} = \lambda_{ic}\mathcal{L}_{ic} + \lambda_{bc}\mathcal{L}_{bc} + \lambda_c \overline{r_c^2} + \lambda_m \left(\overline{r_x^2} + \overline{r_y^2}\right)
```

- Collocation: 20,000 interior points (x, y, t), uniform random, fixed seed, held fixed during training.
- Initial condition: 4,096 interior points at t = 0, target u = v = 0.
- Boundary: 1,000 points per wall over t. Lid: u = tanh(10t), v = 0. Other walls: u = v = 0. Corners left out.
- Derivatives: nested `tf.GradientTape` (second derivatives for the viscous terms), with the training step in `@tf.function`. Mind the chain rule for the input scaling.
- All λ start at 1. If one component exceeds the others by more than 100× after 2,000 steps, adjust once and record it in `config.json` and in DEVIATIONS.
- Log every component (ic, bc, continuity, x-momentum, y-momentum, total) to `history.csv` every 10 steps, and log test-A relative L2 with a wall-clock timestamp every 500 steps.

### Evaluation (one script, `experiments/analysis/evaluate_all.py`, identical for all three methods)

| Group | Metric | On |
| --- | --- | --- |
| Accuracy | MSE and relative L2 for u, v, p (p mean-removed per snapshot) | Test A, test B, full field |
